# Пакет app

Пакет содержит рабочий HTTP-каркас и централизованную конфигурацию. Он не
реализует обработку сообщений покупателей, доступ к SQLite или вызовы LLM.

| Файл | Ответственность и публичный интерфейс |
| --- | --- |
| `__init__.py` | Обозначает Python-пакет; не запускает приложение |
| `config.py` | `Settings` загружает типизированные настройки из окружения и `.env`; `load_settings()` возвращает их либо возбуждает `ConfigurationError` с именами некорректных полей без значений |
| `schemas.py` | `HealthResponse` определяет JSON-контракт `/health`: единственное поле `status` со значением `ok` |
| `main.py` | `create_app()` создаёт FastAPI; `app` — экземпляр для Uvicorn; startup проверяет настройки и сохраняет их в `app.state.settings` |
| `assistant.py` | Описание назначения будущей координации сообщений и бизнес-правил; исполняемой логики нет |
| `llm.py` | Описание назначения будущего адаптера DeepSeek и проверки JSON; вызовов API нет |
| `database.py` | Описание назначения будущих операций SQLite; подключения, таблиц и запросов нет |

Файлы будущих компонентов созданы по уточнению пользователя к карточке 06:
полное утверждённое дерево должно присутствовать, а для отложенной логики
разрешены файлы только с описанием назначения. Они не импортируются рабочими
маршрутами и не объявляют фиктивных функций или классов.

Зависимости: `main.py` использует `config.py` и `schemas.py`. Модель ответа
не зависит от конфигурации. Настройки не зависят от HTTP API. При импорте
`app.main` настройки ещё не читаются: проверка выполняется в lifespan до
обслуживания запросов. Ошибка настроек останавливает старт приложения.

Поток текущего запроса: HTTP `GET /health` → маршрут → `HealthResponse` → JSON.
Настройки и секреты не включаются в ответ или OpenAPI. `create_app()` позволяет
создавать независимые приложения в тестах. На `/health` нет проверок внешних
сервисов: этот endpoint подтверждает только работоспособность процесса API.

`Settings` неизменяемый. `DEEPSEEK_API_KEY` хранится как `SecretStr`, скрывающий
ключ при обычном выводе модели. Значение можно получить явно через
`get_secret_value()`; его нельзя записывать в логи. `load_settings()` заменяет
стандартную ошибку Pydantic на безопасное сообщение. Приоритет источников и
допустимые значения перечислены в корневом README. Загрузка `.env` использует
[Pydantic Settings](https://docs.pydantic.dev/latest/concepts/pydantic_settings/).

При расширении пакета сохраняется направление зависимостей:
`main → assistant → llm/database/schemas`; `llm → schemas`.
`database` не зависит от ассистента и LLM, `config` предоставляет настройки.
Дополнительные слои и пакеты для этих связей не требуются.
