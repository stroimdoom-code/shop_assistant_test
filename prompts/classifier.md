# Инструкция классификатора

Назначение файла — хранить инструкцию для определения намерений, извлечения
явно указанных сущностей и получения структурированного JSON через `app/llm.py`.
Будущие поля результата должны соответствовать моделям в `app/schemas.py`.
Классификатор не принимает бизнес-решений и не формирует ответ покупателю.

В карточке 06 согласовано только описание назначения. Контракт классификации
и рабочий текст инструкции ещё не реализованы; файл не передаётся модели.
